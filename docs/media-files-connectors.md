# Фото, файлы и подключения Джарвис мобайл

Основа: ветка jarvis-brain-0.1, коммит 82643bad3d382dd15a26d2d39ae34b6863f3549c.
Изменения подготовлены в feature/media-files-connectors. APK пока не собран.

В приложении появится кнопка «Фото, файлы и подключения».

## Что добавлено

- Генерация изображения по тексту и изменение выбранного фото через OpenAI Images API.
- Сохранение или отправка результата через Android.
- Выбор фото и документов через системный диалог, без доступа ко всем файлам телефона.
- Чтение TXT, MD, CSV, JSON, кода и DOCX. Сканирование фото и первых 10 страниц PDF.
- Вложение текста документа в следующий вопрос GigaChat после включения разрешения.
- GitHub: список репозиториев, чтение и создание/изменение файла выбранной ветки.
- Vercel: список проектов, развёртываний, создание preview из ветки GitHub.
- Помощник проектов GigaChat: до шести шагов чтения, затем предложение изменения для подтверждения.
- MCP Streamable HTTP: подключение сервера по HTTPS с bearer-токеном, список инструментов и ручной вызов.
- Голосовые команды «мои репозитории», «мои проекты vercel», «создай фото …», «измени фото …».

## Подключение

В разделе «Подключения» выберите сервис и сохраните токен.
GitHub: fine-grained token с доступом к выбранным репозиториям и Contents read/write.
Vercel: токен пользователя/команды; при необходимости заполните teamId.
OpenAI: отдельный ключ API, доступ к gpt-image-1 и баланс API. Подписка ChatGPT не оплачивает API.
GigaChat настраивается в прежних настройках приложения.

Для Vercel репозиторий должен быть доступен GitHub-приложению Vercel.
Для изменения существующего файла GitHub сначала прочитайте его: приложение использует SHA для проверки версии.
Перед применением решения помощника проверьте полное новое содержимое в предложении.

## Проверки и ограничения

39 тестов интерфейса проходят, в том числе отмена изменений, устаревший SHA, отдельное подтверждение предложения помощника и повторные запросы изображений.
Android-компиляция, lint и установка на устройство ещё не выполнены: в локальной среде нет Android SDK/Gradle, а публикация ветки для CI заблокирована автоматической проверкой до отдельного разрешения пользователя.
Сетевые операции с реальными ключами не проверены. Ключи зашифрованы Android Keystore и не возвращаются в интерфейс.

Файлы ограничены 10 МБ; распознанный текст — 12000 символов. OCR использует прежний ML Kit Latin: русский текст может распознаваться плохо. PDF читается через распознавание отрисованных страниц. DOCX — текст документа без форматирования.
Один выбранный файл используется за раз. Форматы старого DOC, XLSX, аудио и видео не анализируются.
MCP-серверы только с OAuth, stdio и старым SSE-транспортом напрямую не поддерживаются. Подключения аккаунта ChatGPT не переносятся в приложение.
Генерация и редактирование фото используют внешнюю платную услугу. Помощник не запускает произвольный код и не публикует production.
