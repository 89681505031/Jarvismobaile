МОЗГ · GIGACHAT

Нейросеть для вопросов и разговора. Команды телефону выполняет сам JARVIS.

Введите Authorization Key для подключения.

По умолчанию оба доступа выключены. Вопросы отправляются в GigaChat через интернет. Проверка связи выполняет один запрос и может учитываться в лимитах API. Не вставляйте сюда чужие или секретные ключи.

Проверка показывает, работает ли запись и доступно ли распознавание Android. Аудио не сохраняется.
🎙️ Активация по имени
Выключено. Для устранения звуков включения/выключения микрофона используется непрерывное офлайн-распознавание, пока приложение открыто.
Модель загружается один раз по вашему выбору. Речь обрабатывается на телефоне, но ожидание расходует заряд.
По умолчанию выключено. Включите переключатель и нажмите «Уйти в фон»: появится постоянное уведомление «JARVIS • микрофон работает в фоне» с кнопкой остановки. Тихая офлайн-активация расходует заряд. В фоне работают время, дата, главные новости, GigaChat-вопросы, напоминания, выбранный умный свет, медиакоманды, фонарик, громкость и системная навигация. Открыть экран нужно только для запуска приложений, звонков, поиска в браузере, чтения личных сообщений и команд, которым требуется геолокация/разрешение Android.
🌦️ Новости и погода
Для погоды и местных новостей можно дать только примерное местоположение. Точная геопозиция и фоновое отслеживание не нужны.
Погода получает приблизительные координаты и округляет их перед сетевым запросом. Местные новости используют название района/города для поиска заголовков; GigaChat может кратко пересказать найденные заголовки.
🗣️ Голос и батарея
Экспериментально. Возможны ошибки из-за звука динамика; микрофон во время ответа остаётся включённым только при открытом приложении.
При заряде ниже 15% фоновый микрофон будет остановлен. Повторное включение — только вручную.
