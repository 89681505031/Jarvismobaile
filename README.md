# Jarvis Mobile

## GigaChat — основной мозг JARVIS HUD 3

В отдельной тестовой Android-сборке **J.A.R.V.I.S. BRAIN** (`com.jarvis.phone.brain`) вопросы, которые не являются разрешёнными локальными командами телефона, направляются в **GigaChat**. Выбранный пользователем персонаж влияет на стиль ответа, но движок ИИ остаётся GigaChat; это приложение в художественном стиле, а не реальный киноассистент.

Настройка: откройте **Настройки → МОЗГ · GIGACHAT**, введите свой GigaChat API **Authorization Key**, выберите scope своего аккаунта (PERS/B2B/CORP) и доступную модель (GigaChat-2, GigaChat-2-Pro или GigaChat-2-Max), сохраните и нажмите **«Проверить подключение»**. Пробный запрос может учитываться в лимитах или оплате API. Без собственного действующего ключа модель не заработает; не пересылайте ключи в переписке и не включайте отключение TLS-проверки. Приложение использует штатную Android-проверку сертификата и уже подключённые доверенные сертификаты Минцифры.

Все открытые вопросы, в том числе голосовые после активации имени, обрабатывает GigaChat. Действия с устройством (разрешённые локальные команды, звонки, переключение звука и т. д.) по-прежнему выполняет **Android-модуль**, а не модель, которая не получает произвольного доступа к системным действиям. Озвучивание не изменено: Fish Audio, если пользователь ввёл его ключ, иначе системный Android TTS; центральный HUD-круг продолжает двигаться при ожидании, прослушивании и псевдоозвучке (выбранный вариант A). В свёрнутом виде поддерживаются существующие локальные голосовые команды; полноценные вопросы к GigaChat пользователь подтверждает, открывая приложение из уведомления.

**Приватность:** два отдельных переключателя передачи **локальных заметок и шести последних диалогов** и **выбранных WhatsApp-сообщений для анализа** по умолчанию выключены. При отключённой передаче истории обычный текущий вопрос всё равно передаётся GigaChat — иначе сервис не сможет ответить. История диалогов может сохраняться локально независимо от этой настройки. Пользователь может очистить локальную историю отдельно от удаления собственного API-ключа. Эти действия не удаляют записи у внешнего поставщика или отдельного облачного шлюза памяти; на соответствующем сервисе действуют его условия хранения. Без согласия на анализ личных сообщений Android зачитывает доступный текст локально, не отправляя его в GigaChat. Отключённая передача контекста также приостанавливает отправку новой истории в опциональный облачный шлюз памяти.

Результат тестового подключения нельзя гарантировать без ключа пользователя и проверки на реальном Android-устройстве с доступом к сервису. Не удаляйте имеющийся HUD3/PLUS ради теста BRAIN: отдельный пакет устанавливается рядом и потребует своих разрешений и офлайн-модели.


## HUD v3 — отдельная тестовая версия с выбранным футуристическим интерфейсом

Новый дизайн «Вариант 3» установлен в HTML/WebView на ветке `design/hud-v3-jarvis-plus`: динамическая центральная «голова» из четырёх тонких HUD-колец и светящегося ядра, радиальные голосовые волны, переработанные карточки приложений, панели, навигация и настройки. **Круг не замирает в ожидании**: энергоэкономичное CSS-дыхание и вращение работают без таймеров JS. При ручном распознавании уровень берётся из фактической оценки громкости Android SpeechRecognizer. При включённом Vosk ожидании имени — только **оценка голосовой активности по частичным словам**, а не измерение акустического уровня. Во время ответа Fish Audio / системного TTS используется выбранный пользователем **вариант A: псевдоанимация слогов**, которая начинается и заканчивается только по реальным событиям озвучивания. Это сознательно не точная привязка к аудиоволне.

Сервис фонового микрофона сохранён: пока приложение свёрнуто, скрытый WebView не рендерит кадры, а запись Vosk может продолжаться по прежним правилам при явно включённом режиме и видимом уведомлении. При `prefers-reduced-motion` динамика отключается для доступности.

Для безопасного тестирования без удаления предыдущего PLUS у HUD v3 отдельное Android-имя `J.A.R.V.I.S. HUD 3` и пакет **`com.jarvis.phone.hud3`**. Внутри нужно заново выдать разрешения и установить офлайн-модель. Подписи от разных GitHub runners могут отличаться: не удаляйте старые приложения и их данные ради установки тестовой сборки.


## JARVIS PLUS — пакет дополнительных функций

В отдельном тестовом APK `com.jarvis.phone.plus` (оптимизирован для 64-битных ARM-телефонов, чтобы не скачивать ненужные x86-библиотеки) собраны все запрошенные дополнительные функции **кроме** непрерывного многовопросного диалога и управления компьютером. Текущая установка `com.jarvis.phone` / `.quiet` / `.background` не заменяется: подпись разработчика для обновления поверх существующего приложения пока не настроена.

- **Прерывание голосом (экспериментально)**: при явном включении в настройках во время ответа работает локальное прослушивание фразы «Джарвис, стоп». Из-за звука самого динамика на разных телефонах точность может отличаться. Повторная команда или непрерывный диалог не запускаются автоматически.
- **Пять голосов персонажей**: уже существующие пять пресетов Fish Audio при введённом пользователем ключе; без ключа — локальные темп и высота Android TTS для каждого персонажа. Наличие разных установленных голосов зависит от движка телефона.
- **Напоминания**: локальный текстовый и голосовой ввод «Напомни через 10 минут …», просмотр из настроек. Используются экономичные неточные Android AlarmManager-напоминания, поэтому доставка может задержаться. Требуются разрешённые уведомления. Отложенная доставка восстанавливается после перезагрузки (без запуска микрофона при загрузке).
- **Расширенный офлайн-набор**: время, дата, сохранённые напоминания и поддерживаемые локальные команды телефона. Облачные вопросы остаются недоступны без сети.
- **Зрение**: только после отдельного нажатия камера или системный выбор конкретного фото; ML Kit распознаёт общие категории изображений и латинский текст локально. Это не полноценное облачное описание сцены, не распознавание лиц и не OCR кириллицы.
- **Умный дом**: вручную указанные HTTPS-сервер Home Assistant, долгосрочный токен и один светильник `light.*`; в тестовой версии управление осуществляется кнопками настроек, не управляет замками или камерами. Соединение с сервером выполняется по команде пользователя.
- **Навыки**: встроенный каталог с локальными переключателями модулей, без скачивания или исполнения стороннего кода.
- **Плавающая кнопка**: после отдельного разрешения Android поверх приложений появляется видимая кнопка J/× для открытия или отключения; сама по себе микрофон не запускает.
- **Обновления**: автоматическая проверка метаданных GitHub Releases один раз в сутки при запуске приложения; при нахождении нового релиза пользователь вручную нажимает кнопку для скачивания и проверки APK. Проверка опубликованного подписанного APK в GitHub Releases и сверка имени Android-пакета, сертификата подписи и номера версии перед передачей Android-установщику. До настройки постоянного CI-подписывающего ключа и публикации релиза обновление существующего APK без удаления не гарантируется. Никогда не удаляйте прежнюю версию ради установки тестовой, чтобы не потерять данные.
- **Экономия батареи**: настройка остановки фонового ожидания через 15/30/60/120 минут или вручную; автоматическая остановка при заряде ниже 15%. Возобновление фонового прослушивания требует пользователя и видимое системное уведомление.

В качестве отдельного тестового приложения PLUS имеет свои разрешения и приватные настройки: русскую офлайн-модель нужно установить ещё раз внутри PLUS. Некоторые возможности требуют внешних сервисов или разрешений; без них кнопки показывают предупреждение. Проверка CI не заменяет проверку звука, микрофона, памяти и энергопотребления на реальном телефоне.


Текущий Android-проект находится в **`mobile/android`**. Это обычные исходники, которые можно открыть в Android Studio. Архив `mobile_fixed.zip`, `patches/` и старые скрипты сохранены для истории; применять их к текущему проекту не нужно.

## Голосовой ввод

Нажмите на круг, разрешите микрофон и дождитесь надписи «Слушаю». Индикатор показывает уровень входящего голоса. После ответа Jarvis открывает следующую голосовую сессию. Повторное нажатие прерывает речь помощника. Если Android не предоставляет сервис распознавания, приложение пробует системное окно голосового ввода и показывает понятную ошибку при его отсутствии.

Обычный системный распознаватель команд приостанавливается, когда приложение свёрнуто. Опциональное фоновое ожидание имён описано ниже. Для голосового ввода не нужен Picovoice AccessKey. Разрешения микрофона можно открыть из настроек приложения. Первичную регистрацию можно пропустить для проверки микрофона.

## Опциональное фоновое ожидание имени (Android)

В **J.A.R.V.I.S. BG**, пока приложение открыто, включите обычную «Активацию по имени» и отдельно отметьте **«Продолжать слушать в свёрнутом виде»**. Для нового отдельного приложения нужно один раз скачать офлайн-модель (~46 МБ); данные предыдущих J.A.R.V.I.S. QUIET и исходного приложения не удаляются. Android 13+ попросит разрешить уведомления, потому что в постоянном уведомлении находится видимая кнопка «Остановить микрофон».

Когда приложение сворачивается, `MainActivity` закрывает свой `AudioRecord` и передаёт захват `WakeForegroundService`, запущенной **из видимой Activity** как `foregroundServiceType="microphone"`. Отдельная постоянная низкоприоритетная нотификация всегда отображает фоновый микрофон и позволяет остановить его. При возвращении в приложение служба отдаёт микрофон UI; две сессии не слушают одновременно. Ни Picovoice, ни постоянного интернет-соединения для ожидания имён нет, и аудио не сохраняется.

В фоне произнесите имя (Джарвис, Астра, Луна, Терра, Сайбер), дождитесь «Слушаю» и назовите простую команду. Также можно сказать «Джарвис, сделай громче» одной фразой. В фоне выполняются только **фонарик, громкость, выключение звука и пауза/переключение музыки**, если соответствующие разрешения уже предоставлены. Для открытия приложений, звонков, сообщений и запросов ИИ сервис **не начинает действие без открытого экрана**: озвучивает просьбу открыть JARVIS и добавляет распознанный запрос в уведомление. При нажатии на уведомление текст появляется в поле команды и выполняется только после нажатия пользователем кнопки ➤.

Фоновый режим по умолчанию **выключен**, требует отдельного явного включения, использует микрофон непрерывно и заметно расходует заряд. Android может завершить службу для экономии энергии; запись не запускается автоматически после перезагрузки или принудительного завершения приложения, пока пользователь снова не откроет его. Доступность при заблокированном экране и политика фоновых сервисов зависят от производителя телефона. Не отключайте системные индикаторы конфиденциальности.

## Тихая активация без повторяющихся звуков микрофона

Ранее ожидание имён многократно запускало `SpeechRecognizer`: на некоторых телефонах Android это вызывает системный звук включения/выключения микрофона каждые несколько секунд. Новая опциональная версия **J.A.R.V.I.S. QUIET** использует `AudioRecord` через открытый движок Vosk и **одну непрерывную локальную сессию** вместо циклического переключения микрофона. Системные звуки самого Android при первоначальном открытии/закрытии аудиосессии приложение не подавляет.

В настройках один раз нажмите **«Установить тихую офлайн-модель»**. Загружается русская `vosk-model-small-ru-0.22` (~46 МБ) с официального сайта Alpha Cephei; архив проверяется по SHA-256 и распаковывается в приватные файлы приложения. После установки включите «Активация по имени». Модель может занимать около 300 МБ оперативной памяти и ускоряет разряд батареи. Слова распознаются локально без отправки аудио на сервер. Для последующей полной голосовой команды используется обычный системный SpeechRecognizer, который может использовать интернет. Без дополнительного разрешения фонового режима микрофон работает лишь пока приложение на экране; при включении нового фонового режима управление записью передаётся уведомляемой службе.

Старая тестовая `com.jarvis.phone.wake` версия остаётся установленной отдельно. У предыдущего тестера идентификатор `com.jarvis.phone.quiet`, а новая фоновая версия J.A.R.V.I.S. BG устанавливается отдельно под `com.jarvis.phone.background`, чтобы не заставлять удалять предыдущие приложения при отличающихся подписях сборок.

## Голосовая активация персонажей

В настройках появился **«Активация по имени»**. После явной установки модели и включения, пока приложение открыто, микрофон непрерывно и локально распознаёт имена «Джарвис», «Астра», «Луна», «Терра» и «Сайбер». Произнесите «Луна» → персонаж ответит «Слушаю», после этого можно сказать команду. Также работает одна фраза: «Джарвис, открой камеру». Выбирается соответствующий персонаж. Говорить «эй» необязательно. Picovoice AccessKey не нужен.

Тихое офлайн-ожидание работает одной сессией и не перезапускает системный SpeechRecognizer после тишины, хотя точность распознавания зависит от микрофона и шума. По умолчанию функция **выключена**, при каждом запуске активируется только после предыдущего выбора пользователя. Без отдельного включения фонового режима при сворачивании приложения распознавание останавливается, а при возвращении восстанавливается. При явном включении нового фонового режима распознавание на устройстве продолжается через foreground-службу с постоянным системным уведомлением.

Офлайн-ожидание потребляет дополнительный заряд, но не передаёт аудио за пределы устройства; системный голосовой движок Android для полных команд может использовать свой облачный сервис. В настройках и на основном экране виден статус ожидания; переключатель позволяет полностью остановить его.

## Диагностика микрофона

В **Настройки → Проверить микрофон (2 секунды)** произнесите несколько слов. J.A.R.V.I.S. проверит, открывается ли Android-аудиопоток, есть ли входящий сигнал и обнаружен ли системный сервис распознавания речи. Проверка выполняется только после нажатия кнопки, исключительно на устройстве; аудиозапись не сохраняется и не отправляется в сеть.

- «Микрофон захватывает звук» при неработающих командах: проверьте системное приложение голосового ввода Android, подключение к сети или офлайн-языковые пакеты.
- «Сигнал очень тихий»: повторите проверку, говоря в микрофон, и убедитесь, что Android разрешил использование микрофона.
- «Android не начал запись» или «Нет разрешения»: проверьте системный переключатель микрофона и разрешения приложения.

Проверка прерывается при сворачивании приложения и не должна работать одновременно с распознаванием речи. Она не заменяет тест на реальном телефоне.

Для проверки на телефоне, где уже стоит старая версия, CI дополнительно собирает **J.A.R.V.I.S. WAKE** с отдельным package ID `com.jarvis.phone.wake`. Она устанавливается рядом с основной версией и прежней тестовой версией J.A.R.V.I.S. TEST, не трогает их данные; позволяет проверить микрофон и новые голосовые имена. У тестового приложения отдельные настройки и разрешения; оно не исправляет подпись старого приложения и не является обновлением.

## Проверки и APK

- `node --test tests/voice-ui.test.cjs` — передача распознанных фраз и обработка состояний интерфейса.
- `npm ci && npm test` в `memory-gateway` — тесты облачного шлюза.
- `gradle testDebugUnitTest lintDebug assembleDebug` в `mobile/android` с JDK 17, Gradle 8.9 и Android SDK 35 — полная сборка, Android Lint и тесты голосовых сессий.

Workflow **Verify Android changes** выполняет проверки после изменений исходников в ветке `fix-microphone-sensitivity` и в pull request. **Build Jarvis Android APK** также можно запустить вручную. APK и отчёты сохраняются в артефактах соответствующей сборки.

Номер версии Android рассчитывается по количеству коммитов исходной ветки (с запасом от старых версий), а не по номеру запуска workflow: ручная и PR-сборки не должны случайно понижать `versionCode`. Для обновления поверх установленного APK нужен тот же ключ подписи в GitHub secret `JARVIS_DEBUG_KEYSTORE_B64`. Если его нет, сборка предупреждает о временной debug-подписи; такой APK не является проверенным обновлением прежней установки.
